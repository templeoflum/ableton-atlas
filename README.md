# Ableton Live, Mapped

A personal study atlas of Ableton Live 12. Open it at the GitHub Pages address for this repository.

Manual illustrations and captions: © Ableton AG, from the [Live 12 manual](https://www.ableton.com/en/live-manual/12/welcome-to-live/). History images are credited on each figure. Independent atlas; not an Ableton publication.

Flags and the session trace are saved in each visitor's own browser (localStorage); nothing is sent anywhere.

This folder is generated by `build-pages.mjs` in the working project. Edit there, rebuild, then commit.
